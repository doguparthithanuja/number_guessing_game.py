# number_guessing_game.py

A simple Python mini project where the player tries to guess a randomly generated number within limited chances.

Features ✨ 
Easy and Hard difficulty levels 
Random number generation 
Limited chances to guess Too High / Too Low hints 
Exception handling for invalid inputs

Difficulty Levels 🎯 
Easy Mode → 10 chances 
Hard Mode → 5 chances

Technologies Used 💻 
Python 
Random Module

Future Improvements 🚀 
Score System 
Replay Option 
GUI Version
